# Images Directory

Place your portfolio images here:

## Recommended Images

1. **profile.jpg** (Optional)
   - Your professional headshot
   - Recommended size: 400x400px
   - Format: JPG or PNG

2. **og-image.jpg** (Recommended for SEO)
   - Social media preview image
   - Size: 1200x630px
   - Shows when you share your portfolio link
   - Should include your name and "Software Engineer"

3. **Project Screenshots** (Optional)
   - Individual project preview images
   - Recommended size: 800x600px
   - Name them: project1.png, project2.png, etc.

## Image Optimization Tips

- Compress images using [TinyPNG](https://tinypng.com/) or [Squoosh](https://squoosh.app/)
- Use WebP format for better performance
- Keep file sizes under 200KB each
- Use descriptive file names (no spaces)

## Current Setup

The portfolio currently uses emoji placeholders for projects (🛍️, 📋, etc.). This works great and loads instantly! But you can replace them with actual images if you prefer.

To use images instead of emojis, modify the `populateProjects()` function in `js/data.js`.
